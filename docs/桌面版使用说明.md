# JobCoach 桌面版 使用说明

> 一份"终身履历" → 每个岗位一键生成定制简历 → AI 教练按 STAR 改写 → 学习计划与面试预测题 + AI 模拟追问。
>
> **数据只保存在你自己的电脑上**，不需要注册账号，也不需要安装 Node.js 或其它开发环境。

---

## 一、安装 / 打开

有两种包，选一个即可：

| 包 | 适用场景 | 使用方法 |
|---|---|---|
| `JobCoach-1.0.0-portable.exe`（绿色便携版） | 不想在本机留下安装记录、U 盘随身带 | **双击即用**（首次启动约需 10~20 秒解压） |
| `JobCoach-Setup-1.0.0.exe`（安装包） | 长期使用，想要桌面图标 | 双击 → 选择安装目录 → 安装 → 桌面/开始菜单打开 |

### 首次打开被 Windows 拦了怎么办？
因为软件没有购买数字签名证书，Windows 可能提示"Windows 已保护你的电脑"：
- 点 **更多信息** → **仍要运行**
- 若公司终端安全软件拦截（提示"已阻止"），请联系 IT 将 JobCoach 加入白名单

## 二、第一次使用：配置 AI（必做一次）

软件所有 AI 功能（解析 JD、推荐经历、STAR 改写、生成备考包、模拟面试）都需要一个大模型服务。

1. 注册 DeepSeek 开放平台：<https://platform.deepseek.com>
2. 登录后进入 **API Keys** → 创建新密钥 → 复制 `sk-` 开头的那一串
   （按量计费，充 5~10 元就够用很久）
3. 打开 JobCoach → 右上角 **⚙ 齿轮** → 点「DeepSeek」快捷按钮自动填好地址与模型
4. 把密钥粘贴到 **API Key** 输入框 → **保存**
5. 点 **测试连接**，出现"连接成功"即可

### 支持的服务商

| 服务商 | 协议 | Base URL | 模型示例 |
|---|---|---|---|
| DeepSeek | OpenAI 兼容 | https://api.deepseek.com | deepseek-chat |
| Kimi | OpenAI 兼容 | https://api.moonshot.cn/v1 | moonshot-v1-8k |
| 智谱 | OpenAI 兼容 | https://open.bigmodel.cn/api/paas/v4 | glm-4-flash |
| 通义千问 | OpenAI 兼容 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |
| ChatGPT | OpenAI 兼容 | https://api.openai.com/v1 | gpt-4o-mini / gpt-4o |
| Claude | **Anthropic 原生** | https://api.anthropic.com | claude-sonnet-4-5 |
| OpenRouter | OpenAI 兼容 | https://openrouter.ai/api/v1 | anthropic/claude-sonnet-4.5 |
| Ollama 本地 | OpenAI 兼容 | http://localhost:11434/v1 | qwen2.5:14b |

> 密钥只存本机数据库；软件直连你选择的服务商。**Claude 要选「Anthropic 原生」协议**（点 Claude 快捷按钮会自动切换）；其余服务商都用「OpenAI 兼容」。

> 在设置里点对应快捷按钮会自动填好「接口协议 + Base URL + 模型名」，只需粘贴各自的 API Key。
> 密钥只保存在你本机数据库里，软件直接与你选择的服务商通信，不经过任何第三方。

## 三、怎么用（三个页面）

### ① 个人履历 —— 先攒素材
- 按「教育经历 / 工作经历 / 项目经历 / 技能 / 荣誉」录入你的经历，**越具体越好**（数字、规模、结果）
- 每次保存自动留一个版本，「历史版本」里可一键回退
- 「AI 流水账拆亮点」：把大白话工作记录贴进去，AI 帮你拆成 STAR 风格的简历亮点
- 「素材库」：沉淀可复用的好段落

### ② JD 工作台 —— 出定制简历（四步）
1. 粘贴目标岗位的 JD（至少 30 字）→ 保存 → 点「解析」，AI 提取要求与关键词
2. 点卡片上的「打开」→ **推荐经历**：AI 按匹配度打分，勾选要进简历的经历
3. **定制简历**：自动组装，算关键词命中率；命中词高亮、缺失词红色提醒
4. **AI 教练**：逐条按 STAR 改写，逐条「采纳 / 拒绝」，可「回填到母版履历」或「存素材库」
5. **预览与导出**：导出 **Word**、打印存 **PDF**，或导出 **JSON**

### ③ 备考中心 —— 面试准备
- 选择 JD（也可以先"不选择"看看都有哪些岗位）
- 点「生成备考包」（约 20~60 秒）：得到 2~4 周学习计划（可勾选进度）+ **每周推荐项目与交付物（带网址）** + 15+ 道面试预测题
- 每道题点「模拟追问」，AI 当面试官与你多轮对话，会点评并继续追问
- 可「导出 Markdown」，手机上随时看

## 四、数据与备份（重要）

| 内容 | 位置 / 方法 |
|---|---|
| 数据文件 | `%APPDATA%\JobCoach\data\jobcoach.db`（单个文件，复制即完整备份） |
| 打开数据文件夹 | 软件菜单 **文件 → 打开数据文件夹** |
| 自动备份 | 每次启动自动备份到同目录下 `backups\`，保留最近 20 份 |
| 手动导出/恢复 | 右上角 ⚙ → 底部「导出全库备份」/「恢复备份」 |

- **换电脑**：把 `jobcoach.db` 拷到新电脑的同一位置即可
- ⚠️ 不要把数据文件夹发到群里或网盘：里面包含你的简历内容和 API Key

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 双击后没反应 / 白屏 | 等 10~20 秒（便携版首次要解压）；再不行重启电脑后重试 |
| 提示被安全软件拦截 | 联系 IT 将 JobCoach 加入白名单 |
| 提示"API Key 无效或已过期" | 到平台确认密钥可用、余额充足；重新创建密钥再填一次 |
| 提示"无法连接 AI 服务" | 检查是否联网；确认 Base URL 正确（DeepSeek 为 `https://api.deepseek.com`） |
| AI 返回格式异常 | 点重试；或换一个模型（设置里改模型名） |
| 生成备考包很慢 | 正常需 20~60 秒，请保持窗口打开 |
| 想彻底重来 | 关闭软件 → 把 `data\jobcoach.db` 改名备份 → 重新打开即为空库 |

## 六、隐私说明

- 所有履历、JD、备考包、设置都存放在你本机的 SQLite 文件里，**不上传任何服务器**
- AI 调用时，你主动触发的文本（如 JD 内容、简历亮点）会发送给你配置的 AI 服务商（如 DeepSeek）
- API Key 以明文保存在本机数据库中，请勿把数据文件外发
