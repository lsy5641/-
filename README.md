# JobCoach 求职助手

一份"终身履历" + 每个岗位 JD 一键衍生定制简历 + AI 教练（STAR 改写）+ 备考中心（学习计划 / 面试预测题 / 模拟追问）。

**当前进度：M1~M9 全部完成**（含界面重构与多轮体验优化）。

---

## 一、功能总览

### ① 个人履历（终身母版）
- 按「教育经历 → 工作经历 → 项目经历 → 技能 → 荣誉」分组维护，教育经历置顶
- 每次保存自动留版本，最近 50 版可随时回退
- **AI 流水账拆亮点**：把大白话工作记录拆成 STAR 风格 bullet，勾选后一键入库
- 素材库：沉淀可复用的 STAR 段落（AI 教练采纳的改写可一键存入）

### ② JD 工作台（四步出成品）
1. **推荐经历**：粘贴 JD → AI 解析要求与词条 → AI 按匹配度打分推荐经历（也可手动勾选）
2. **定制简历**：组装成该岗位简历，计算关键词命中率，黄底高亮命中词、红色列出缺失词
3. **AI 教练**：逐条按 STAR 改写，预览"原文 vs 建议 + 补强环节 + 理由"，逐条采纳/拒绝，可回填母版或存入素材库
4. **预览与导出**：成品预览 + 导出 JSON / Word(.docx) / 打印存 PDF

### ③ 备考中心
- 选择 JD（支持"不选择 JD"查看岗位列表）
- **一键生成备考包**：2~4 周学习计划（每周任务可勾选进度）+ **每周交付物/推荐项目（名称 + 真实网址）** + 15+ 道面试预测题（项目深挖/技术/行为 STAR/HR，带答题提示）
- **学习进度总览**：总进度条 + 每周小进度
- **AI 模拟追问**：任意题目进入多轮对话练习，面试官会先点评再追问，回答太空泛时引导你用 STAR
- 导出 Markdown（面试前手机可看）

### 界面与体验
- 设计规范：`design-system/jobcoach/MASTER.md`（Minimalism/Swiss · 海军蓝 `#1E3A5F` · Plus Jakarta Sans）
- 品牌标识：纯黑底 + 白色 J 字标（同时作为浏览器 favicon）
- 细节：页面/面板切换采用慢速交叉淡入、骨架屏、引导式空态、步骤条、Esc 关闭弹窗、键盘焦点环、移动端适配

## 二、开始使用（网页版）

**最简单：双击 `start-jobcoach.bat`**
等待浏览器自动打开 `http://127.0.0.1:5173` 即可（使用期间别关黑窗口，关掉即停止）。

手动方式：

```powershell
cd C:\vagent-workspace\jobcoach
npm install        # 首次
npm run dev        # 以后每次
```

### 第一次使用：接入 AI（DeepSeek）

1. 注册 <https://platform.deepseek.com> → 「API Keys」→ 创建并复制密钥（`sk-` 开头）
2. 软件右上角 **⚙ 齿轮** → 点「DeepSeek」快捷按钮 → 粘贴密钥 → 保存
3. 点「测试连接」，出现"连接成功"即可使用全部 AI 功能

> 密钥只存本机数据库；软件直连你选择的服务商（DeepSeek / Kimi / 智谱 / 通义 / Ollama）。

## 三、数据与备份

| 内容 | 位置 |
|---|---|
| 主数据库 | `data/jobcoach.db`（单个文件，复制即完整备份） |
| 启动自动备份 | `data/backups/`（每次启动自动备份，保留最近 20 份） |
| 手动导出/恢复 | 设置弹窗底部：导出全库备份 JSON / 选择文件恢复（恢复前有确认） |

- 履历、JD、词条、备考包、AI 配置都在同一数据库里
- ⚠️ `data/` 含个人信息与 API Key，**不要上传网盘或在群里转发**

## 四、开发

```powershell
npm run dev        # 同时启动前后端（http://127.0.0.1:5173）
npm test           # 后端自动化测试（当前 60 个用例）
npm run typecheck  # TypeScript 类型检查
npm run build      # 构建前端到 dist/web（生产模式由后端托管）
npm start          # 生产模式（http://127.0.0.1:3001）
```

### 目录结构

```
jobcoach/
├── server/src/            后端（Express + sql.js，纯 JS 无原生依赖）
│   ├── ai/client.ts       OpenAI 兼容客户端（JSON 修复重问）
│   ├── routes/            profile / materials / jds / keywords / coach / exam / export / backup / mock / settings
│   └── db.ts              建表、版本快照、设置读写
├── web/src/               前端（React + Vite）
│   ├── pages/             个人履历 / JD 工作台 / 备考中心
│   └── components/        详情四步、简历预览、模拟面试、设置弹窗等
├── design-system/         设计系统（ui-ux-pro-max 生成）
├── docs/superpowers/      设计文档与各阶段实现计划
└── data/                  数据库与自动备份（不入库）
```

### 常见报错

| 现象 | 解决 |
|---|---|
| `node 不是内部或外部命令` | 装 Node LTS 并重开终端 |
| `EADDRINUSE: 3001/5173` | 上次没退干净：关掉重复终端或重启 |
| 浏览器打不开 127.0.0.1:5173 | 看黑窗口是否报错；稍等几秒按 F5 |
| `npm install` 网络失败 | 挂代理或 `npm config set registry https://registry.npmmirror.com` 后重试 |
| 公司安全软件拦截 | 本项目纯 JS 无原生模块；如被拦请联系 IT 加白 |
