========================================
  JobCoach 求职助手（桌面版）使用说明
  版本 1.0.0
========================================

一份"终身履历" → 每个岗位一键生成定制简历 → AI 教练按 STAR 改写
→ 学习计划 + 面试预测题 + AI 模拟追问。

【重要】数据只保存在你自己的电脑上，不需要注册账号，
        也不需要安装 Node.js 或其它开发环境。


----------------------------------------
一、安装 / 打开
----------------------------------------
有两种包，选一个即可：

1) JobCoach-1.0.0-portable.exe（绿色便携版）
   - 双击即用，无需安装（首次启动约 10~20 秒解压）
   - 适合 U 盘随身带、不想留安装记录

2) JobCoach-Setup-1.0.0.exe（安装包）
   - 双击 → 选择安装目录 → 安装
   - 会创建桌面和开始菜单快捷方式，可正常卸载

首次打开被 Windows 拦截怎么办：
- 若提示"Windows 已保护你的电脑"：点【更多信息】→【仍要运行】
  （因为软件未购买数字签名证书）
- 若公司终端安全软件拦截：请联系 IT 将 JobCoach 加入白名单


----------------------------------------
二、第一次使用：配置 AI（必做一次）
----------------------------------------
所有 AI 功能（解析 JD、推荐经历、STAR 改写、生成备考包、
模拟面试）都需要一个大模型服务。

1. 注册 DeepSeek 开放平台：https://platform.deepseek.com
2. 登录后进入 API Keys → 创建新密钥 → 复制 sk- 开头的那串
   （按量计费，充 5~10 元够用很久）
3. 打开 JobCoach → 右上角【齿轮 ⚙】→ 点「DeepSeek」按钮
4. 把密钥粘贴到 API Key → 点【保存】
5. 点【测试连接】，出现"连接成功"即可

也支持 Kimi、智谱、通义、本地 Ollama 等兼容 OpenAI 协议的服务
（设置里改 Base URL 与模型名即可）。
密钥只保存在你本机，软件直接与 AI 服务商通信，不经过第三方。


----------------------------------------
三、怎么用（三个页面）
----------------------------------------
① 个人履历 —— 先攒素材
   - 按 教育 / 工作 / 项目 / 技能 / 荣誉 分组录入经历
   - 越具体越好（数字、规模、结果）
   - 每次保存自动留版本，可随时回退
   - 「AI 流水账拆亮点」：大白话贴进去，自动拆成 STAR 亮点
   - 「素材库」：沉淀可复用的好段落

② JD 工作台 —— 出定制简历（四步）
   - 粘贴目标岗位 JD → 保存 → 点「解析」（AI 提取要求与关键词）
   - 点卡片「打开」→ ①推荐经历：AI 按匹配度打分，勾选经历
   - ②定制简历：自动组装并计算关键词命中率（缺失词会红色提示）
   - ③AI 教练：逐条 STAR 改写，逐条采纳/拒绝，可回填母版或存素材库
   - ④预览与导出：导出 Word、打印存 PDF、或导出 JSON

③ 备考中心 —— 面试准备
   - 选择 JD（也可以先"不选择"查看岗位列表）
   - 「生成备考包」（约 20~60 秒）：2~4 周学习计划（可勾选进度）
     + 每周推荐项目与交付物（带网址）+ 15+ 道面试预测题
   - 任意题目点「模拟追问」，AI 当面试官与你多轮对话并点评追问
   - 可导出 Markdown，手机随时看


----------------------------------------
四、数据与备份（重要）
----------------------------------------
数据文件：
  %APPDATA%\JobCoach\data\jobcoach.db
  （单个文件，复制它就是完整备份）

打开数据文件夹：软件菜单【文件】→【打开数据文件夹】
自动备份：每次启动自动备份到同目录 backups\（保留最近 20 份）
手动导出/恢复：右上角齿轮 → 底部「导出全库备份」/「恢复备份」

换电脑：把 jobcoach.db 拷到新电脑同一位置即可。
⚠ 不要把数据文件夹发到群里/网盘：里面包含你的简历与 API Key。


----------------------------------------
五、常见问题
----------------------------------------
Q: 双击后没反应 / 白屏？
A: 等 10~20 秒（便携版首次要解压）；仍不行请重启电脑再试。

Q: 提示被安全软件拦截？
A: 联系 IT 将 JobCoach 加入白名单。

Q: 提示 "API Key 无效或已过期"？
A: 到平台确认密钥可用、余额充足，重新创建密钥再填一次。

Q: 提示 "无法连接 AI 服务"？
A: 检查联网；确认 Base URL 正确（DeepSeek 为
   https://api.deepseek.com）。

Q: AI 返回格式异常？
A: 点重试，或在设置里换一个模型。

Q: 生成备考包很慢？
A: 正常需要 20~60 秒，请保持窗口打开。

Q: 想彻底重来？
A: 关闭软件 → 把 data\jobcoach.db 改名备份 → 重新打开即为空库。


----------------------------------------
六、隐私说明
----------------------------------------
- 履历、JD、备考包、设置全部保存在你本机的 SQLite 文件里，
  不上传任何服务器
- AI 调用时，你主动触发的文本会发送给你配置的 AI 服务商
  （如 DeepSeek）
- API Key 以明文保存在本机数据库，请勿把数据文件外发
